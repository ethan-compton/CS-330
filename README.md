How do I approach designing software?

When I design software, I start by breaking the project into smaller parts so I can focus on one thing at a time. For this 3D scene, I planned out each object, like the laptop, phone, notebook, mug, and pen, and thought about how they would fit together to make a realistic setup. I paid attention to proportions, shapes, and how lighting would affect everything before I started coding.
Throughout the project, I learned how important it is to plan ahead but also stay flexible. Sometimes an idea that looked good in my head didn’t work in the program, so I had to adjust and try again. This project helped me build patience and a better understanding of how design and logic work together in software.

How do I approach developing programs?

When developing programs, I like to start simple and build up from there. I began this project by creating basic shapes and testing how they looked in the scene before adding more details like textures and lighting. I tested my program often so I could catch mistakes early instead of getting stuck later on.
I also learned to organize my code better by keeping things like object creation, lighting, and transformations separate. That made it easier to find and fix problems as I worked. Over time, I noticed how much small improvements added up, which is something I will keep doing in future projects.

How can computer science help me reach my goals?

Computer science helps me turn ideas into real, working projects. It gives me the tools to think through problems and find logical ways to solve them. This course taught me how much creativity and problem-solving go into building even something as simple as a 3D scene.
These skills will help me in other areas of software development, like designing interfaces or creating games. I also gained a better understanding of how code can shape user experiences. Overall, this project showed me that computer science is about more than just coding. It is about creating something functional and meaningful through problem-solving and design.
